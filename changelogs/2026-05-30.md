# Changelog - 2026-05-30

## Resumen de la Sesión
En esta sesión se realizaron optimizaciones de rendimiento y de Core Web Vitals en el tema de Metapack, se corrigieron errores críticos de navegación y filtrado, y se implementó un **Motor SEO B2B Nativo** completo (eliminando dependencias de plugins externos como RankMath). Adicionalmente, se configuró el CPT de "Casos de Éxito", se unificaron las estadísticas del Customizer con la página de Quiénes Somos y se corrigieron advertencias de PHP 8.x en el plugin de respaldo WPvivid. Por último, se subieron todos los cambios locales pendientes al repositorio remoto, se optimizó el rendimiento móvil y la accesibilidad del tema en una segunda fase (minificando activos, resolviendo problemas de contraste WCAG, y agregando etiquetas aria-label), y se generó el paquete ZIP distribuible del tema.

## Cambios Detallados

### Componente: Tema Metapack (`metapack-theme`)

- **Motor SEO B2B Nativo (Sin Plugins)**:
  - `functions.php`:
    - Creación de metaboxes de edición SEO para Páginas, Entradas, Productos y Casos de Éxito (Título, Descripción, Keywords, Imagen OG).
    - Implementación de guardado de metadatos SEO.
    - Creación de función `metapack_seo_tags()` para inyectar dinámicamente metatags SEO y Open Graph en `wp_head` con fallbacks B2B predefinidos ( Inicio, Quiénes Somos, Productos, Maquila, Blog) del checklist.
    - Implementación del filtro `document_title_parts` para sobrescribir dinámicamente el tag `<title>` de WordPress.
  - `template-parts/header-metapack.php`: Remoción del tag `<title>` estático para evitar duplicados en el HTML.

- **Unificación de Métricas**:
  - `page-quienes-somos.php`: Se reemplazaron estadísticas estáticas por llamadas dinámicas a `get_theme_mod()` vinculadas al Customizer, unificándolas con las estadísticas de la página de inicio.

- **Registro de CPT y Customizer**:
  - `functions.php`: Registro formal del Custom Post Type `caso_exito` (Casos de Éxito) con soporte para editor de bloques Gutenberg.
  - `functions.php`: Registro del campo `contact_cf7_id` en el Customizer.
  - `template-parts/contact-metapack.php` y shortcode `metapack_contact_form`: Vinculación dinámica del formulario CF7 con el ID del Customizer.

- **Carga de Fuentes y Mixed Content**:
  - `functions.php`: Se removió la encolación remota de fuentes desde Google Fonts (`metapack-fonts`) y se eliminó como dependencia de la hoja de estilos principal.
  - `template-parts/header-metapack.php`: Se corrigió el fallback de URL de logo a `https://` para evitar mixed content.

- **Imágenes y Core Web Vitals (LCP/CLS)**:
  - `front-page.php`, `page-maquila.php`, `page-quienes-somos.php`, `template-parts/footer-metapack.php`: Se migraron las imágenes hardcodeadas de formato `.png`/`.jpg` a versiones `.webp` ya comprimidas en el servidor. Se agregaron dimensiones explícitas (`width` y `height`) y `loading="lazy"` para evitar Cumulative Layout Shift (CLS).
  - `single-producto.php`: Se reemplazaron imágenes fijas y miniaturas de ACF por la función estándar `wp_get_attachment_image()` para la generación automática de resoluciones responsivas (`srcset`) y dimensiones correctas.

- **Catálogo y Filtros**:
  - `archive-producto.php`: Se corrigió el selector en la llamada JavaScript (`.mp-product-card` -> `.mp-product-card-v2`) para que las búsquedas y filtros en tiempo real funcionen correctamente sobre la nueva estructura de tarjetas.

- **Optimización de Rendimiento y Accesibilidad Móvil**:
  - **Accesibilidad HTML**:
    - `template-parts/contact-metapack.php`: Agregado atributo `title` descriptivo al mapa iframe.
    - `template-parts/footer-metapack.php`: Agregados atributos `aria-label` descriptivos a los enlaces de WhatsApp, Instagram, YouTube y al botón flotante.
    - `front-page.php` y `page-maquila.php`: Agregados atributos `aria-label` a los botones prev/next del carrusel de maquila y a los puntos de paginación de los sliders.
    - `home.php`, `page-productos.php` y `single.php`: Agregados atributos `aria-label` descriptivos a los enlaces que envuelven las imágenes destacadas de blog y productos.
    - `front-page.php`: Cambiado `h3.mp-kpi-card__title` por `h2` para mantener una estructura jerárquica de encabezados descendente.
  - **Estilos y Contraste (CSS)**:
    - `assets/css/metapack-styles.css`: Modificado el color de la variable `--mp-gray` de `#828283` a `#595959` para cumplir con la relación de contraste WCAG AA 4.5:1.
    - `assets/css/metapack-styles.css`: Agregada clase `.screen-reader-text` para ocultar texto de forma accesible.
    - `assets/css/metapack-styles.css`: Incrementado el padding táctil y márgenes en los enlaces de email del footer (`padding: 6px 0`, `margin-bottom: 8px`) para cumplir con el estándar de touch target size.
  - **Asset Optimization y CF7**:
    - `functions.php`: Desactivada la carga remota de Google Fonts de Elementor mediante filtros (`elementor/frontend/print_google_fonts`).
    - `functions.php`: Agregado filtro `script_loader_tag` para añadir el atributo `defer` a `metapack-script` y evitar bloqueo de hilo principal.
    - `functions.php`: Configurado el encolado de estilos y scripts para cargar las versiones minificadas `metapack-styles.min.css` y `metapack-script.min.js`.
    - `functions.php`: Implementado filtro `wpcf7_form_elements` para envolver dinámicamente selects y file inputs en etiquetas `<label>` con texto de accesibilidad oculto.

### Componente: WPvivid Backup & Restore (Fuera del repositorio de Git)
- `class-wpvivid-mysqldump.php`: 
  - Declaración de la propiedad interna `$dsn` para compatibilidad con PHP 8.2+.
  - Corrección de docblocks de tipo de retorno en `getTableColumnTypes()`, `escape()` y `getColumnStmt()` para resolver las advertencias del analizador estático relacionadas con `implode()` e iteración de tipos.
  - Corrección de la interpolación obsoleta `${var}` a la sintaxis estándar `{$var}` en múltiples líneas del archivo.

### Componente: Sistema
- `robots.txt` (Nuevo): Creado un archivo robots.txt estático optimizado en la raíz del sitio.
